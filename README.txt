================================================================
  📅 개인용 구글 캘린더 텔레그램 봇  (Netlify Functions)
================================================================

텔레그램에서 봇에게
   "오늘 일정"   →  오늘 하루 일정
   "이번 주 일정" →  이번 주(월~일) 일정
   "일정 추가"   →  날짜 선택 후 새 일정 등록
을 하면 깔끔하게 정리해서 답장해 주고, 캘린더에 직접 추가도 합니다.


----------------------------------------------------------------
■ 1. 환경변수 이름 목록  (Netlify에 등록할 4개)
----------------------------------------------------------------
아래 4개를 Netlify 사이트의
 Site settings → Environment variables 에 등록하세요.

 (1) TELEGRAM_BOT_TOKEN
       - 텔레그램 봇 토큰
       - 예) 1234567890:AAH...xyz

 (2) GOOGLE_CALENDAR_ID
       - 일정을 가져올 캘린더 ID
       - 보통 본인 Gmail 주소 (예: leily.yoon@gmail.com)

 (3) GOOGLE_SERVICE_ACCOUNT_EMAIL
       - 구글 서비스 계정 이메일
       - 예) calbot@my-project.iam.gserviceaccount.com

 (4) GOOGLE_PRIVATE_KEY
       - 서비스 계정 JSON 파일 안의 "private_key" 값 전체
       - "-----BEGIN PRIVATE KEY-----\n....\n-----END PRIVATE KEY-----\n"
       - 줄바꿈(\n)이 포함된 그대로 한 줄로 붙여넣으면 됩니다.
         (코드에서 자동으로 실제 줄바꿈으로 변환합니다.)


----------------------------------------------------------------
■ 2. 구글 캘린더 준비 (서비스 계정 방식 — 토큰 만료 없음)
----------------------------------------------------------------
 1) https://console.cloud.google.com 접속 → 프로젝트 생성
 2) "API 및 서비스" → 라이브러리 → "Google Calendar API" 사용 설정
 3) "사용자 인증 정보" → 사용자 인증 정보 만들기 → "서비스 계정" 생성
 4) 만든 서비스 계정 → "키" 탭 → 키 추가 → JSON 다운로드
      - JSON 안의 client_email  → GOOGLE_SERVICE_ACCOUNT_EMAIL
      - JSON 안의 private_key    → GOOGLE_PRIVATE_KEY
 5) ★중요★ 본인 구글 캘린더를 서비스 계정과 "공유"하기
      - 구글 캘린더(웹) → 내 캘린더 → 설정 및 공유
      - "특정 사용자와 공유" 에 위 client_email 추가
      - 권한: "일정 변경" (Make changes to events) 선택
        ※ 조회만 할 거면 "모든 일정 세부정보 보기"로도 되지만,
          "일정 추가" 기능을 쓰려면 반드시 "일정 변경" 권한이어야 합니다!
      (이 단계를 빼먹으면 일정이 안 보이거나 추가가 안 됩니다!)


----------------------------------------------------------------
■ 3. 텔레그램 봇 만들기
----------------------------------------------------------------
 1) 텔레그램에서 @BotFather 검색 → /newbot
 2) 이름/아이디 정하면 봇 토큰을 줍니다 → TELEGRAM_BOT_TOKEN


----------------------------------------------------------------
■ 4. Netlify 배포
----------------------------------------------------------------
 방법 A) Netlify 웹사이트에 이 폴더를 드래그&드롭으로 배포
 방법 B) GitHub에 올린 뒤 Netlify에서 연결

 - 배포 후 1번의 환경변수 4개를 등록하고 "재배포(Redeploy)" 하세요.
 - 함수 주소는 다음과 같습니다:
     https://<사이트이름>.netlify.app/.netlify/functions/telegram


----------------------------------------------------------------
■ 5. 텔레그램 웹훅 연결 (딱 한 번만 실행)
----------------------------------------------------------------
 아래 주소를 브라우저 주소창에 넣고 한 번 열면 됩니다.
 (토큰과 사이트이름을 본인 것으로 교체)

 https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<사이트이름>.netlify.app/.netlify/functions/telegram

 "ok":true 가 나오면 연결 완료!


----------------------------------------------------------------
■ 6. 사용법
----------------------------------------------------------------
 [조회]
   "오늘 일정"  / "이번 주 일정"  이라고 보내면 답장이 옵니다.
   일정이 없으면 "없어요"라고 알려줍니다.
   (또는 봇에게 /start 를 보내면 버튼 메뉴가 나옵니다.)

 [추가]
   1) "일정 추가" 라고 보내거나, 메뉴의 [✏️ 일정 추가] 버튼을 누릅니다.
   2) 날짜 버튼(오늘 ~ 7일 후) 중 하나를 선택합니다.
   3) 안내 메시지에 "답장(reply)"으로 일정을 입력합니다. 형식:
        14:00 회의            → 14:00~15:00 (1시간 기본) 일정
        14:00-15:30 점심 약속 → 시작/종료 시간 지정
        종일: 휴가            → 종일 일정
        장보기                → 시간 없으면 종일 일정으로 등록
   4) "✅ 일정이 추가되었어요!" 메시지가 오면 캘린더에 반영 완료.
